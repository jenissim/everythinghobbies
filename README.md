# Everything Hobbies — Website V1

This is a complete static website for Everything Hobbies.

## Files

- `index.html` — homepage
- `explore.html` — explore hobbies
- `books.html` — book club
- `journal.html` — journal/articles
- `about.html` — about page
- `join.html` — email signup page
- `style.css` — all styling
- `script.js` — menus, filters, voting demo and signup demo
- `assets/hero.jpg` — the launch artwork you supplied

## How to edit

Open the `.html` files in a code editor such as VS Code.

Most text is directly inside the HTML, so you can search for a phrase and replace it.

## Important: the signup form

The signup form is currently a front-end demo. It shows a confirmation message but does NOT store emails.

Before launch, connect it to a free form/email service (for example Formspree, Buttondown, Mailchimp, or a Google Form) so actual email addresses are collected.

## Instagram

Replace the `href="#"` Instagram links with the real Everything Hobbies Instagram URL when you are ready.

## Publishing for free

This is a static site, so it can be hosted free on services such as GitHub Pages, Netlify, or Cloudflare Pages.

The easiest beginner route is usually Netlify: upload the website folder and it will give you a live URL.
